ระบบนี้ช่วยแปลงเอกสาร "ใบเบิกวัตถุดิบ / Production Order" จากกระดาษหรือไฟล์ภาพ ให้เป็นข้อมูลดิจิทัลโดยอัตโนมัติ ด้วย AI

2. บทบาทผู้ใช้งาน (Roles)

บทบาทสิทธิ์การใช้งาน
Admin ใช้งานได้ทุกฟีเจอร์ — สแกน, อนุมัติ, จัดการผู้ใช้, ตั้งค่า AI, ตั้งเวลาสแกนอัตโนมัติ, Export, ดูประวัติ, ปรับ Permission Matrix
Supervisor สแกน, ตรวจสอบ/แก้ไข, อนุมัติรายการ, ดูประวัติการใช้งาน, Export Excel
Staff สแกน/อัปโหลดเอกสารเข้าคิว, ดูรายการ, Export Excel

Admin สามารถปรับสิทธิ์แต่ละ Role ได้ที่หน้า "ผู้ใช้งาน" → Permission Matrix

4. การสแกนเอกสาร

4.1 อัปโหลดไฟล์เข้าคิว

มี 3 วิธี:

ถ่ายด้วยกล้องเปิดกล้อง (webcam/มือถือ) ถ่ายเอกสารทีละแผ่น — ถ่ายได้หลายรูปต่อเนื่อง แต่ละรูปจะเข้าคิวทันที
เลือกไฟล์เลือกไฟล์ภาพ (JPG, PNG, WebP) หรือ PDF จากเครื่อง — เลือกได้หลายไฟล์พร้อมกัน
Google Driveตั้งค่าโฟลเดอร์ Drive ที่หน้า "ตั้งค่า" → ระบบดึงไฟล์จากโฟลเดอร์เข้าคิวอัตโนมัติทุกรอบสแกน

4.2 คิวรอสแกน

ไฟล์ที่อัปโหลดจะแสดงเป็นตารางด้านล่าง ประกอบด้วย:

  • ชื่อไฟล์ — ชื่อไฟล์ต้นฉบับ (คลิก Preview ดูภาพได้)
  • สถานะ — pending (รอ) / success (สำเร็จ) / failed (ล้มเหลว)
  • ดำเนินการ — ปุ่ม Preview ดูภาพ หรือ ลบไฟล์ออกจากคิว

4.3 เริ่มสแกน

กดปุ่ม "สแกนทั้งหมด" → ระบบจะประมวลผลไฟล์ทีละไฟล์ พร้อมแสดงความคืบหน้า เช่น "กำลังสแกน 2/5 — receipt.jpg"

ระบบตรวจซ้ำ: หาก Production Order เดียวกัน (เลขที่ซ้ำ) มีอยู่แล้ว ระบบจะข้ามไฟล์นั้นโดยอัตโนมัติ

4.4 สแกนอัตโนมัติ

Admin สามารถตั้งเวลาสแกนอัตโนมัติได้ที่หน้า "ตั้งค่า" — ระบบจะดึงไฟล์จาก Google Drive + ประมวลผลคิวตามเวลาที่กำหนด

5. รายการ & การแก้ไข

5.1 ดูรายการ

หน้า "รายการ" แสดง Production Order ทั้งหมดเรียงจากใหม่สุด สามารถกรองด้วย Dropdown ด้านบน:

  • ทั้งหมด — แสดงทุกสถานะ
  • รออนุมัติ — เฉพาะรายการที่ยังไม่ได้อนุมัติ
  • อนุมัติแล้ว — เฉพาะรายการที่อนุมัติแล้ว

5.2 แก้ไขรายการ

คลิกปุ่ม แก้ไข ที่รายการนั้น → เปิดหน้าต่างแก้ไขที่แสดง:

  • ส่วนหัว — Production Order, วันที่, Series No., ชื่อผลิตภัณฑ์
  • ยอดผลิต — Plan vs จริง (แสดง % เปรียบเทียบ)
  • ตารางรายการ (Lines) — แต่ละแถวแสดง: ลำดับ, รหัส, รายการวัตถุดิบ, Type, Qty (ที่เขียนด้วยมือ), Plan, คลัง, หน่วย
  • ภาพต้นฉบับ — คลิกดูภาพที่สแกนเข้ามา (ขยาย/ย่อได้)

แก้ไขค่าใดก็ได้ตามต้องการ สามารถ + เพิ่มแถว หรือ ลบแถว ได้

5.3 บันทึกฉบับร่าง (Draft)

กดปุ่ม "บันทึกฉบับร่าง (Draft)" เพื่อบันทึกการแก้ไขไว้ก่อน โดยยังไม่อนุมัติ

  • บันทึกทุกการเปลี่ยนแปลงรวมถึงการ Tick ยืนยันค่าต่าง
  • สถานะจะเปลี่ยนเป็น ฉบับร่าง
  • สามารถกลับมาแก้ไขเพิ่มเติมได้ในภายหลัง

5.4 นำทาง (Navigation)

ใช้ปุ่ม ◀ / ▶ มุมขวาบนของหน้าต่างแก้ไข เพื่อข้ามไปรายการก่อนหน้า/ถัดไป โดยไม่ต้องปิดหน้าต่าง

6.1 ยืนยันค่าต่าง

แต่ละแถวจะมี checkbox "✓ ยืนยันค่าต่าง" — ต้อง Tick ครบทุกแถวก่อนจึงจะอนุมัติได้

  • เปรียบเทียบค่า Qty (ที่เขียนด้วยมือ) กับ Plan (ตามแผน)
  • หาก Qty ≠ Plan → แถวจะแสดง highlight สีเหลือง เพื่อเตือนให้ตรวจสอบ
  • Tick เพื่อยืนยันว่าตรวจสอบค่าต่างแล้ว ถูกต้อง

6.2 การอนุมัติ

เมื่อ Tick ยืนยันครบทุกแถว → ปุ่ม "✓ อนุมัติรายการนี้" จะเปิดให้กดได้

เมื่ออนุมัติแล้ว:
  • ระบบบันทึกการแก้ไขล่าสุดทั้งหมดก่อนอนุมัติ
  • สถานะเปลี่ยนเป็น อนุมัติแล้ว
  • ภาพต้นฉบับจะถูกลบออกจากระบบเพื่อประหยัดพื้นที่
  • รายการจะเป็น แบบอ่านอย่างเดียว — ดูได้แต่แก้ไขไม่ได้
  • พร้อม Export เป็น Excel

7. Export Excel

ไปที่หน้า "รายการ" → ส่วนด้านล่าง:

  1. เลือกช่วงวันที่ (ไม่บังคับ — เว้นว่าง = ทั้งหมด)
  2. เลือกกรองตาม "วันที่บนเอกสาร" หรือ "วันที่สแกน"
  3. กดปุ่ม "Export เป็น Excel"
สำคัญ: Export จะรวมเฉพาะรายการที่ อนุมัติแล้ว เท่านั้น — รายการที่ยังรออนุมัติจะไม่ถูกรวมในไฟล์ Excel

ไฟล์ Excel ที่ได้:

  • มี Dropdown กรอง/เรียงลำดับในตัวทุกคอลัมน์
  • ตรึงหัวตาราง (Freeze Panes)
  • พร้อมเปิดใน Excel / Google Sheets

8. จัดการผู้ใช้งาน (Admin)

เฉพาะ Admin เท่านั้นที่เข้าถึงหน้านี้ได้:

8.1 เพิ่มผู้ใช้ใหม่

  1. กรอก อีเมล ของผู้ใช้ใหม่
  2. ตั้ง รหัสผ่าน เริ่มต้น (อย่างน้อย 6 ตัวอักษร)
  3. กรอก ชื่อ (ไม่บังคับ)
  4. เลือก บทบาท (Role) — Staff / Supervisor / Admin
  5. กดปุ่ม "สร้างผู้ใช้"

8.2 แก้ไข Role

ในรายการผู้ใช้ คลิก Dropdown ข้าง Role เพื่อเปลี่ยนบทบาท → ระบบบันทึกทันที

8.3 Permission Matrix

ตาราง Checkbox แสดงสิทธิ์แต่ละ Role — Admin สามารถ Tick/Untick เพื่อปรับสิทธิ์ แล้วกด "บันทึกสิทธิ์"

Admin จะมีสิทธิ์ "ผู้ใช้งาน", "ตั้งค่า" และ "แดชบอร์ด" ติดตัวเสมอ ไม่สามารถยกเลิกได้ เพื่อป้องกันการล็อกตัวเอง

9. ตั้งค่าระบบ (Admin)

9.1 ตั้งเวลาสแกนอัตโนมัติ

ทุกๆ N ชั่วโมงสแกนคิวอัตโนมัติตามช่วงเวลาที่กำหนด (เช่น ทุก 3 ชม.)
ทุกๆ N นาทีสำหรับทดสอบ — สแกนถี่ขึ้น
เวลารายวันระบุชั่วโมงที่ต้องการ เช่น 8,13,17 = สแกนวันละ 3 รอบ
ปิดปิดสแกนอัตโนมัติ — สแกน manual เท่านั้น

9.2 โฟลเดอร์ Google Drive

  1. สร้างโฟลเดอร์ใน Google Drive
  2. แชร์โฟลเดอร์ให้ Service Account Email (คัดลอกได้จากหน้าตั้งค่า) ด้วยสิทธิ์ Editor
  3. วางลิงก์โฟลเดอร์ → กด "บันทึก"
  4. ระบบจะดึงไฟล์ใหม่เข้าคิวอัตโนมัติ แล้วย้ายไฟล์ที่ดึงแล้วไปโฟลเดอร์ย่อย "scanned"

9.3 ตั้งค่า AI

เลือกผู้ให้บริการ AI สำหรับอ่านลายมือ:

Claude (Anthropic)แม่นยำสูง เหมาะกับลายมือภาษาไทย
Gemini (Google)ราคาประหยัด ประสิทธิภาพดี
GPT (OpenAI)ทางเลือกเพิ่มเติม

กรอก API Key ของแต่ละผู้ให้บริการ → กด "บันทึก" — คีย์เก็บฝั่ง Server เข้ารหัสปลอดภัย ไม่แสดงคีย์เต็ม

10. คำถามที่พบบ่อย (FAQ)

Q: สแกนแล้วชื่อผลิตภัณฑ์ผิด ทำอย่างไร?
A: คลิกแก้ไขรายการ แล้วแก้ช่อง "ผลิตภัณฑ์" ด้วยมือ → บันทึก Draft หรืออนุมัติได้เลย ระบบอ่านชื่อจากแถวแรกของตาราง (คอลัมน์ สินค้า/รายการวัตถุดิบ)
Q: Qty (ตัวเลขเขียนด้วยมือ) อ่านผิด?
A: เปิดภาพต้นฉบับเทียบ แล้วแก้ไขค่า Qty ในตารางรายการ → Tick ยืนยันค่าต่าง
Q: อัปโหลดไฟล์ซ้ำจะเกิดอะไรขึ้น?
A: ระบบตรวจซ้ำด้วยเลข Production Order — หากซ้ำจะข้ามไฟล์นั้นโดยอัตโนมัติ
Q: อนุมัติแล้วแก้ไขได้ไหม?
A: ไม่ได้ — รายการที่อนุมัติแล้วจะเป็นแบบ Preview เท่านั้น ไม่สามารถแก้ไขหรือลบได้ เพื่อความถูกต้องของข้อมูล
Q: Export Excel ไม่เห็นบางรายการ?
A: Export รวมเฉพาะรายการที่อนุมัติแล้ว — ตรวจสอบว่าอนุมัติครบหรือยัง
Q: มือถือใช้ได้ไหม?
A: ได้ — ระบบรองรับ Responsive Design มีแถบเมนูด้านล่างสำหรับมือถือ สามารถถ่ายรูปจากกล้องมือถือได้โดยตรง
Q: ข้อมูลหลังเส้นปะ (column J เป็นต้นไป) จะถูกสแกนไหม?
A: ไม่ — ระบบอ่านเฉพาะคอลัมน์ "ลำดับ" ถึง "หน่วย" (ฝั่งซ้ายของเส้นปะ) เพื่อความรวดเร็ว
